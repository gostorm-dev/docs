go-storm Documentation

The most accurate load testing engine. Detects when YOUR generator is the bottleneck.

What is go-storm?

go-storm is a high-performance HTTP load testing engine written in Go. Unlike other tools that only show you results, go-storm tells you whether those results are trustworthy by monitoring the load generator itself.

Key Differentiator: go-storm is the only load testing tool that detects generator saturation — it monitors CPU, memory, GC pressure, goroutines, file descriptors, and worker utilization in real-time.

Quick Install

go install github.com/gostorm-dev/go-storm@latest

Quick Start

# Basic load test
storm run -u https://example.com -n 1000 -c 50

# With capacity estimation
storm run -u https://example.com -n 5000 --estimate

# With saturation monitoring (default: enabled)
storm run -u https://example.com -n 10000 -c 100

Features

  • Generator Saturation Detection — 7 real-time factors
  • Health Reports — Actionable recommendations
  • Capacity Estimation — Know your limits before testing
  • Connection Pooling — 25x more connections per host
  • HTTP/2 Support — Multiplexed connections
  • Streaming Aggregation — O(1) memory, no sorting
  • Distributed Testing — Scale across machines
  • Prometheus Metrics — Real-time monitoring

Why go-storm?

Every other load testing tool shows you results. go-storm shows you whether those results are trustworthy.

When your load generator is saturated, your results are meaningless. go-storm detects this and tells you exactly what's happening.
