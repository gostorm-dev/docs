Installation

Install go-storm in under 60 seconds.

Install from Source

go install github.com/gostorm-dev/go-storm@latest

Requires Go 1.21 or later.

Download Binary

Download the latest binary from GitHub Releases.

PlatformArchitectureDownload
Linuxamd64go-storm-linux-amd64
Linuxarm64go-storm-linux-arm64
macOSamd64go-storm-darwin-amd64
macOSarm64go-storm-darwin-arm64
Windowsamd64go-storm-windows-amd64.exe

Build from Source

git clone https://github.com/gostorm-dev/go-storm.git
cd go-storm
go build -o storm .
sudo mv storm /usr/local/bin/

Verify Installation

storm --version
Tip: On Linux/macOS, you may need to add /usr/local/bin to your PATH.
