Quick Start

Run your first load test in under 60 seconds.

1

Install go-storm

go install github.com/gostorm-dev/go-storm@latest
2

Run a Basic Load Test

storm run -u https://example.com -n 100 -c 10

This sends 100 requests with 10 concurrent workers.

3

Check the Results

go-storm will show you:

  • Total requests and success rate
  • Latency percentiles (p50, p95, p99)
  • Requests per second
  • Generator health report — is your generator saturated?
Key Feature: The health report tells you if your generator is the bottleneck. If worker utilization is above 95%, your generator can't keep up — not your target.

Common Commands

# Basic load test
storm run -u https://example.com -n 1000 -c 50

# With capacity estimation
storm run -u https://example.com -n 5000 --estimate

# With rate limiting (1000 RPS)
storm run -u https://example.com -n 5000 -c 100 -r 1000

# JSON output
storm run -u https://example.com -n 1000 --format json --output results.json

# With Prometheus metrics
storm run -u https://example.com -n 5000 --metrics-port 9091
